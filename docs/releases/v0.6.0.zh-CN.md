# PVM Runtime 0.6.0 — Public Preview

[English](v0.6.0.md)

PVM Runtime 0.6.0 把之前的 Runtime 基线整理成可在现有项目中实际评估的一套交付：
选择性老项目迁移、可携带桌面迁移工具、三端增量原生渲染，以及由 GitHub 直接托管
的项目网站现在会随同一个版本发布。

## 主要更新

### 选择性迁移老项目

- 可以扫描和转换单个类、多个指定类、单个模块、多个模块或组合范围，并且不修改旧
  项目源码。
- 生成可人工复核的 DSL 骨架与机器可读迁移报告。
- 源码快照漂移、复核项未关闭、Capability 未批准、DSL 结构无效或行为探针不一致时，
  都会阻止迁移结果进入签名阶段。

### PVM Migration Studio

- 使用 C++17/Qt 实现“扫描 → 转换 → 复核 → 验证”桌面流程。
- 提供 Windows x64、macOS Apple Silicon 和 macOS Intel 可携带压缩包。
- 随包携带迁移后端、C++17 验证器、必需协议文件、日志与进度显示；输出目录与旧项目
  保持分离。

### 三端增量原生渲染

- UI Wire v2 发送带版本的增量补丁；C ABI v1–v3 继续兼容完整树传输。
- Android 复用 RecyclerView 行，iOS 更新 UICollectionView/UIKit/SwiftUI 节点，
  HarmonyOS 执行带 Key 的 ArkUI 变更。
- 三端 Host 会合并渲染任务、拒绝过期 Revision、丢弃取消后的迟到回调，并让 VM
  求值避开平台主线程。
- 性能门禁覆盖增量更新、完整重绑、列表复用和主线程记账开销。

### iOS 生命周期恢复

- Demo 已迁移到 UIScene 生命周期，并能在真实的后台、终止和重新启动序列后恢复 VM
  持久化状态。
- Simulator 自动验证覆盖计数、文本输入、异步状态与状态恢复。

### 分发与社区入口

- Android AAR/Maven、iOS XCFramework/Binary Swift Package 和 HarmonyOS HAR 均为
  预编译产物，接入方无需编译 Runtime 源码。
- Release 新增可直接安装体验的 Android Demo APK，并明确使用 Debug 签名。
- 仓库已经提供中英文贡献流程、社区行为准则、Discussions、Topics、社交预览素材，
  以及零依赖 GitHub Pages 官网。

## 兼容性

- Runtime 5 与 PVBC v5 仍是当前格式；本版本没有提升字节码格式版本。
- Runtime 5 继续读取 PVBC v1–v5。
- Mobile C ABI v4 选择 UI Wire v2；C ABI v1–v3 保留完整树传输。
- Android Runtime 最低 SDK 为 24，独立 Demo 最低 SDK 为 33。
- iOS 二进制 SDK 最低为 iOS 15，包含 arm64 真机与 arm64/x86_64 Simulator Slice。
- HarmonyOS HAR 兼容 API 23，并使用 DevEco API 24 构建。

## 验证方式

Release Commit 必须通过 Core、Android、Apple、KMP、Container、Website 和桌面打包
工作流；SDK 压缩包附带 SHA-256。Release 中的 Android Demo APK 使用 Android Debug
Key，仅用于体验；正式业务 App 应使用 Runtime SDK，并配置自己的 Application ID、
嵌入模块、权限与签名。

实现细节见[三端接入指南](../PLATFORM_INTEGRATION.zh-CN.md)、
[迁移指南](../MIGRATION.zh-CN.md)和[性能设计](../PERFORMANCE.zh-CN.md)。
